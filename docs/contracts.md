# Cross-language contracts

origine is Zig + Rust + C header + JS. Every place where one language must agree with another is
a *contract surface*. For each surface this page names the source of truth, what is generated or
checked, what to update when something changes, and the command that verifies it.

Commands:

| command | what it does |
|---|---|
| `just gen-contracts` | rewrites every committed generated file (`rust/scripts/contracts.sh gen`) |
| `just check-contracts` | regenerates into a temp tree and fails on any difference, compiles the Zig-generated C check with clang, checks exported-symbol prefixes, runs `zig build test-io -Dtypescript=false` (Zig vs header). Part of `just check`. |
| `just check-rust` | clippy + Miri; the Rust-vs-header comparisons are compile-time checks and fail here |

Generated files carry an `@generated` banner and are never edited by hand. Sites that are
maintained by hand carry a `CONTRACT (docs/contracts.md, surface X)` comment.

## Inventory

| | surface | source of truth | automation |
|---|---|---|---|
| A | `origine_io.h` <-> `src/io/c_api.zig` <-> `sys.rs` <-> `mock.rs` | the header | generated + checked |
| B | Rust natives <-> Zig registration (`host.zig`) <-> JS `native.*` names | `#[native(path = ..)]` in Rust | registry generated by the macro, Zig iterates it, JS checked by a script |
| C | `OriginCfg` and the `origine_api_*` C ABI <-> Zig externs | `rust/crates/origine_api/include/origine_api.h` | generated + checked |
| D | `Errno` Zig <-> Rust errno table <-> JS tables | `src/api/errno_codes.zig` | generated + checked |
| E | `origine_oxc.h` <-> Rust `origine_oxc` <-> Zig `oxc_abi.zig` | the header | checked (both sides) |
| F | exported / kept symbol lists | `kept_symbol_prefixes` in `build.zig` | generated + checked |

## A. I/O C API (`src/io/include/origine_io.h`)

Source of truth: `src/io/include/origine_io.h`.

* **Zig** (`src/io/c_api.zig`, `op.zig`, `backend.zig`): `src/io/contract_test.zig` parses the
  header text and compares, for every `oio_*` function, the name set (both ways), `callconv(.c)`,
  and parameter/return ABI classes (integer width and signedness, pointer, const-ness of data
  pointers); every struct (`oio_op`, `oio_stat`, `oio_options`, `oio_iovec`): field names, order,
  offsets, sizes, total size; every `#define`/enum constant against `op.Kind`, `op.O`,
  `backend.Caps`, `backend.Kind`, `backend.Mode`, `op.FallocFlags`, `op.fd_cwd` (both ways).
  Runs in `zig build test-io`. (`zig translate-c` / `@cImport` is not used: it does not terminate
  on the macOS SDK headers.)
* **Rust** `rust/crates/origine_io/src/sys_gen.rs` is generated from the header by bindgen
  (`rust/crates/origine_gen`, subcommand `io-sys`). `sys.rs` only includes it (and, under Miri,
  re-exports the fakes).
* **Miri fake** `rust/crates/origine_io/src/mock.rs` stays hand-written, but the generated
  `for_each_oio_fn!` macro lists every header function: a function without a fake fails to compile
  under Miri, and `signatures_match_the_header` fails when a fake's signature differs from the
  generated extern declaration. Constants and structs come from `sys`.

Generator rules (also in the header comment): name every function parameter; a `#define` written
with a `ull` suffix becomes `u64`; `OIO_FDCWD` is typed `oio_fd`; C enums are typed `i32`
(`oio_kind`) / `c_int` (`oio_run_mode`) because the header uses them as `int32_t kind` / `int mode`.

When you change the header (new op, field, flag):
1. edit `origine_io.h`;
2. Zig: `op.zig` (`Kind`, `Op`, `O`, ...), `backend.zig` (`Caps`, ...), `c_api.zig` (`pub export fn`
   with the same parameters), the backends;
3. `just gen-contracts` (regenerates `sys_gen.rs`);
4. Rust: the safe wrapper in `origine_io/src/lib.rs` and the fake in `mock.rs` (the compiler tells you);
5. `just check-contracts` and `just check-rust`.

## D. Errno

Source of truth: the `Errno` enum in `src/api/errno_codes.zig` (std-only so a tool can import it).

* JS (`origine:@std/errno`, `native.errors`): generated at compile time from the enum
  (`errno.module_source`, `errno.table`); nothing to do.
* Zig `errno.Error` mirrors the enum by hand; a `comptime` block in `errno.zig` fails the build
  when an `Errno` member has no `Error` member (the reverse already fails in `errno.of`).
* Rust `rust/crates/origine_api_core/src/errno_table.rs` (numbers, names, `ALL`, `name_of`) is
  generated by `src/gen_contracts.zig`. The `io::ErrorKind`/raw-errno *policy* in `errno.rs`
  stays by hand: it is Rust-specific.

Adding a code: add the member to `errno_codes.zig` (never reuse or renumber), add it to `Error` in
`errno.zig`, map it in `errno.zig`'s `lookup` if std names differ, `just gen-contracts`, then add
the arm in `origine_api_core/src/errno.rs` if a Rust error should produce it.

## E. oxc C ABI (`rust/crates/origine_oxc/include/origine_oxc.h`)

Source of truth: the header. Three parties, each checked against it:

* **Zig** declarations live in `src/api/transform/oxc_abi.zig` (std only). `src/gen_contracts.zig`
  turns them into `src/api/transform/oxc_abi_check.c` (static asserts for sizes, offsets and field
  types, plus C prototypes); `just check-contracts` compiles it with `clang -fsyntax-only` against
  the header, so any layout, field-type or prototype difference is a compile error.
* **Rust** `origine_oxc/src/header_abi.rs` is generated from the header by bindgen
  (`origine_gen oxc-abi`). `origine_oxc/src/lib.rs` (`mod abi_check`) fails to compile when the
  hand-written `#[repr(C)]` structs differ (field names/types via struct literals, offsets, sizes),
  when the status/flag/version constants differ, or when the `extern "C"` functions have a
  different signature.
* Bumping the ABI: edit the header and `ORIGINE_OXC_ABI_VERSION`, `ABI_VERSION` in `lib.rs`,
  `abi_version` in `oxc_abi.zig`; update the structs/prototypes on both sides;
  `just gen-contracts`.

## F. Exported / kept symbols

`kept_symbol_prefixes` in `build.zig` (`origine_`, `crdtp__`, `v8_inspector__`) is the only list:
the macOS `-exported_symbols_list` file and the Linux `objcopy --keep-global-symbol` arguments are
generated from it (the old `rust/exports.macos.txt` is gone). `rust/scripts/check-exports.sh`
(part of `check-contracts`) fails when a `#[no_mangle]` function in a Rust crate does not start
with a kept prefix. A Zig `extern fn` without a Rust definition is a link error. Not exercised
automatically: the macOS release external-link and Linux `ld -r` paths (they need V8's `ld64.lld`
/ a Linux host).

## B. Natives registry (Rust -> Zig -> JS)

Source of truth: the `#[native(side_effect = .., path = "namespace.name", needs = .., promise)]`
attribute on each Rust native (`rust/crates/origine_api/src/fs.rs`, `io.rs`).

* The macro emits `NATIVE_<NAME>: RawNative { callback, side_effect, path, needs }`. One line per
  native in `NATIVES` (`origine_api/src/registry.rs`) lists them; a unit test scans the module
  sources and fails when a `#[native]` fn is missing from the list, listed twice, or has a
  malformed/duplicate path. (Rust has no portable distributed registration without a new
  dependency, so this one list stays by hand, right next to the natives and test-checked.)
* Rust exports the registry as `origine_api_natives_count()` / `origine_api_natives_get()`
  (surface C). `Host.install` (`src/api/host.zig`, `installRustNatives`) iterates it and builds
  `native.<namespace>.<name>` with the declared callback and side effect, gated by `needs`
  (`runtime`: only with `Config.runtime`; `async_fs`: also needs async fs). There is no native
  name, symbol or side effect written on the Zig side, and no per-native C symbol any more.
* JS: `rust/scripts/check-natives.sh` (part of `check-contracts`) fails when a registered native is
  never referenced by `src/js/glue/*.js` (as `native.ns.name`, `ops.name` or a chained `.name(`) or
  when the glue uses a `native.<registered namespace>.<name>` that is not registered. The managed
  API tests (`zig build test`) exercise the natives end to end.

Adding a native: write the fn with `#[native(..)]`, add `module::NATIVE_<FN>,` to `NATIVES`, use
`native.<ns>.<name>` in the glue (`src/js/glue/`), `just check-contracts`.
Renaming or removing one: change the attribute, the glue and the list; nothing in Zig.

## C. `origine_api` C ABI (`rust/crates/origine_api/include/origine_api.h`)

Source of truth: the header (`origine_api_cfg`, `origine_api_native`, the side-effect/needs enums,
`origine_api_attach_isolate | detach_isolate | configure | poll | has_work | pollable | wake`,
`origine_api_natives_count | get`).

* **Rust**: `origine_api/src/abi_gen.rs` is generated by bindgen (`origine_gen api-abi`). `OriginCfg`
  is the generated `origine_api_cfg`; `lib.rs` (`abi_signatures`) and the enum asserts in
  `registry.rs` fail to compile when an `extern "C"` function or enum number differs from the header.
* **Zig**: `src/api/api_abi.zig` (std only) declares the structs, enums and prototypes;
  `src/gen_contracts.zig` writes `src/api/api_abi_check.c` from them and `just check-contracts`
  compiles it against the header with clang (layouts, field types, constants, prototypes).
  `host.zig` takes everything from `api_abi.zig`.
* Changing the ABI (a new `OriginCfg` field, a new entry point): edit the header, then
  `api_abi.zig`, `just gen-contracts`, then the Rust definitions (the compiler points at them) and
  `host.zig`. Semantics belong in `docs/async-host-contract.md`.
