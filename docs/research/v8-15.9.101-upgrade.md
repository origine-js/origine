# V8 15.9.101 compared with Origine’s 15.8.30 pin

Research date 2026-11-05. Both [Bazel](../../MODULE.bazel) and [Zig/GN](../../lib/v8_zig/build/v8.build.zig) pin 15.8.30. Upstream cut [15.8.30](https://github.com/v8/v8/commit/a98309795399032afd2f191adaa94ed6e9918437) on October 21 and [15.9.101](https://github.com/v8/v8/commit/123617cb05ca531d290cfdb9a978949956d7c850) on November 5. The [tag comparison](https://github.com/v8/v8/compare/15.8.30...15.9.101) diverges by one release commit on the old side and 646 commits on the new side, including 645 mainline commits. The [exact mainline range](https://chromium.googlesource.com/v8/v8/+log/5433bc8dcaf6bc8428c04579abcb1bb52a74df20..cfcfc8344d9c981e90f860fa4cc648fcd7a11593) and tagged sources underpin the selected changes below.

## Embedder interface changes

- **Removed callback accessors and aliases.** V8 removed `FunctionCallbackInfo::Data()` and `PropertyCallbackInfo::Data()` and broadened template data parameters to `Local<Data>`. It removed old accessor and named setter/definer aliases and the deprecated indexed `*CallbackV2` aliases. Origine still calls `Data()` from [binding.cc](../../lib/v8_zig/binding/binding.cc) and [rusty.cc](../../lib/v8_zig/binding/rusty.cc), and the Zig shim still names four removed indexed aliases. Migrate those aliases to their unsuffixed names. Use `DataV2()` and preserve the existing Value-only callback contract at the C/Rust boundary by checking or narrowing the payload, or deliberately propagate the broader type through every caller. [Data accessors](https://github.com/v8/v8/commit/e111538f125a) · [Callback aliases](https://github.com/v8/v8/commit/1de7db979859)
- **Fast API payload ABI.** `FastApiCallbackOptions::data` becomes a private `Local<Data>` exposed through `DataV2()`. [Zig](../../lib/v8_zig/src/v8/fast_api.zig) and [Rust](../../lib/v8_zig/rusty_v8/src/fast_api.rs) mirror the struct, and [native dispatch](../../src/api/binding.zig) reads its data slot. Check size, alignment, offset and handle representation under both build paths. A C++ accessor can insulate callers from the private field. [Fast API header](https://github.com/v8/v8/blob/15.9.101/include/v8-fast-api-calls.h)
- **Context setters are deprecated.** `SetEmbedderDataV2` and `SetAlignedPointerInEmbedderData` still exist with stronger deprecation annotations. The replacements have fixed slot bounds, so check the bounds before switching [Origine’s fixed slots](../../src/managed/context_slots.zig). Preserve dynamic slot behavior for [vendored Rust callers](../../lib/v8_zig/rusty_v8/src/context.rs). [Deprecation](https://github.com/v8/v8/commit/7239471e19dd) · [Replacement contracts](https://github.com/v8/v8/blob/15.9.101/include/v8-context.h)
- **External string lifetime.** V8 moves resource ownership into a `cppgc` wrapper. Disposal can wait until a `cppgc` sweep, and off-thread code-cache deserialization of known-resource external strings is forbidden. Origine’s [mmap module loader](../../src/api/context.zig) unmaps source in the resource finalizer. Verify mapping retention and exactly-once deallocation across collection, context disposal, and isolate teardown. Check the Zig and Rust destructor calls to external memory accounting in those paths. [Ownership change](https://github.com/v8/v8/commit/79971a758104)
- **Inspector.** `V8StackTrace` gains `isTopScriptOpaque()`. Origine passes V8-provided stack trace pointers, so rebuild the inspector shim. Inspector clients using both `awaitPromise` and `throwOnSideEffect` can synchronously unwrap a fulfilled Promise. Other Promise states can produce `EvalError`. Untrusted clients have tighter isolate ID and `terminateOnResume` handling. [Stack trace API](https://github.com/v8/v8/commit/fd4e29003938) · [Promise evaluation](https://github.com/v8/v8/commit/7bedc5f48948) · [Untrusted CDP](https://github.com/v8/v8/commit/205922abe6a4)
- **Other new interfaces.** V8 adds context-free `Map::Get`, process-wide paired crash key callbacks, and `WasmModuleObject::OwnedBuffer::as_span()` with deprecated public buffer fields. [Map](https://github.com/v8/v8/commit/30909431cb16) · [Crash keys](https://github.com/v8/v8/commit/886954384a2e) · [Wasm buffer](https://github.com/v8/v8/commit/3502b086e069)

## Origine migration sequence

An ordered `git apply --check` probe used the exact 15.9.101 copies of the 28 files touched by the existing V8 patch series. `0001-intrinsics.patch` and `0002-hardening.patch` applied. [`0003-no-date.patch`](../../lib/v8_zig/build-tools/patches/v8/0003-no-date.patch) stopped the sequence because the upstream `DateConstructor` now passes a span to `NewStringFromUtf8`. Later patches still need ordered validation after rebasing that hunk.

1. **Roll source pins and toolchains.** Use `just bazel-bump-v8 15.9.101` for [MODULE.bazel](../../MODULE.bazel), then refresh the lockfile through the normal build. The bump script updates V8 and its Chromium source pins and hashes the new Clang archive. The target changes fast_float, ICU, libc++, libc++abi, LLVM libc and Chromium buildtools. Update the Zig V8 version, the patch checkout path in the [binding justfile](../../lib/v8_zig/justfile), and the separately pinned depot_tools package URL and hash. GN also rolls PartitionAlloc and Chromium zlib. Both build paths need matching headers, build defines and archive. The vendored Rust crate links the same archive as Zig. [Upstream DEPS](https://github.com/v8/v8/blob/15.9.101/DEPS) · [Zig package pins](../../lib/v8_zig/build.zig.zon) · [Rust linking](../../lib/v8_zig/docs/rusty.md)
2. **Rebase the two patch series.** Preserve the intrinsic installer and guest hardening, Date removal, mimalloc, stack bounds, Wasm policy, PGO, and REPL behavior. Drop local changes for the three removed experimental APIs from the [immutable installers patch](../../lib/v8_zig/build-tools/patches/v8/0006-immutable-installers-native-stack.patch) while preserving the surviving `SharedStructType` handling. Check ICU’s lazy-data patch against the rolled ICU sources and then apply the Bazel overlay patches on top of the shared V8 series. [Shared patches](../../lib/v8_zig/build-tools/patches/v8) · [Bazel patches](../../build/bazel/patches/v8)
3. **Migrate shims and regenerate bindings.** Fix the removed APIs above. In `lib/v8_zig`, run `zig build gen`, `zig build check-generated` and `zig build check-bindings` against the new headers. Regenerate Rust bindgen output through the normal build paths. Update the runtime version gate and both version tests. Revalidate the patched engine's intrinsic inventory against a pristine context and run the guest hardening tests. `bootstrap.js` consumes the engine-supplied array, so its version annotation can follow those checks. [Binding targets](../../lib/v8_zig/build/binding.build.zig) · [Runtime gate](../../src/managed/runtime.zig) · [Bootstrap](../../src/js/bootstrap.js) · [Capabilities tests](../../src/tests/managed/capabilities.zig)
4. **Regenerate snapshots and PGO.** Build the embedded V8 and Origine snapshots using the new engine and target settings. [Runtime cache keys](../../src/api/init_cache.zig) already include the V8 version and code-cache tag, so old init caches naturally miss. Zig/GN can use `-Dbuiltin_pgo=false` during bring-up. For the normal macOS arm64 PGO build, retrain the custom profile and produce matching metadata for 15.9.101. Google publishes the [15.9.101.0 baseline metadata](https://storage.googleapis.com/chromium-v8-builtins-pgo/by-version/15.9.101.0/meta.json) with x86/x64 profiles, and Origine merges its custom arm64 data with the x64 baseline. The upstream [GN](https://github.com/v8/v8/blob/15.9.101/BUILD.gn) zlib option is separate from Origine’s [Bazel release-small](../bazel-migration-progress.md) snapshot compression. [Local PGO procedure](../../lib/v8_zig/build-tools/pgo/README.md)
5. **Validate both builds.** Use `just bazel-patch-v8`, `just bazel-build-v8`, `just build dev`, `just build release-small` and `just examples` for the Bazel path, and `just patch-v8`, `just build-v8`, `just test` and `just test-repl` for Zig/GN. In `lib/v8_zig`, run the Rust suite with inspector enabled and `zig build test-icu-lazy`. Exercise mmap-backed imports, Fast API payloads, inspector evaluation, guest intrinsic and Wasm policies, snapshots, and cold and warm cache starts. Compare stripped binary size, startup latency, RSS and GC behavior on representative workloads. [Build recipes](../../justfile) · [Bazel release gates](../bazel-migration-progress.md)

Build compatibility and Origine performance require a migrated build. Upstream microbenchmarks describe their own workloads.
